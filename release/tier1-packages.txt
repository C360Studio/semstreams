# Tier 1 — the frozen Go package set (ADR-106).
#
# These are the semstreams packages that a sister repository actually imports. They become semver-binding
# at 1.0: an incompatible change here breaks an adopter's build, and after 1.0 costs a major version.
#
# Derived 2026-09-02 from the union of `import` statements across the nine framework consumers in the
# docs-site stage table (semsource, semteams, semdev, semconnect, semboids, semmachina, semlink, semops,
# semdragon). It is COMMITTED rather than recomputed: CI has no sister checkouts, and a set that silently
# shrinks when a sister is unavailable would relax the freeze exactly when it matters.
#
# Adding a line is a deliberate widening of the 1.0 compatibility promise. Removing one needs the same
# scrutiny as any Tier 1 break: if a sister still imports it, removal IS the break.
#
# The other 91 non-internal packages are Tier 2 — explicitly not frozen, and the lane where the pre-RC
# surface-removal pass continues to work.
#
#
# TWO PACKAGES DELIBERATELY EXCLUDED. The derivation above found them in sister imports, but they do not exist at
# HEAD, so they are migration debt rather than frozen surface:
#
#   pkg/ownership        — deleted 2026-08-05 by dbdc9bd8 (refactor(graph)!: typed mutations and exact reads).
#                          semops still has 51 import sites and semdragon 3; both are pinned before the deletion,
#                          so nothing is broken today and both are hard-blocked from migrating until those are
#                          rewritten. This is the concrete cost behind semops sitting at beta.114.
#   input/github-webhook — absent at HEAD; semdev has 1 import site.
#   engine, flowstore,   — retired 2026-08-27 by #1116 (ADR-100 D5, "retirement without aliases"). semteams
#   flowtemplate           imports all three; the migration is written up in
#                          docs/operations/migration-beta162-to-beta163.md, which names the exact broken import
#                          lines at cmd/semteams/main.go:24-26. semteams is pinned at beta.160, i.e. the last tag
#                          before the retirement, so this is the first thing its migration hits.
#
# They are named here, not silently dropped: an excluded line that leaves no trace is how a migration blocker
# becomes invisible. scripts/api-compat.sh independently reports any listed package that loads at neither end, so
# re-adding either by accident is caught rather than ignored.
#
# NOT covered by this file (guarded elsewhere, see ADR-106): the 33 component schemas in schemas/
# (task schema:check-changes), the payload envelope, the entity-ID grammar (ADR-102), the subject
# namespace (ADR-093/098).
