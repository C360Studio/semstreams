# Exported NATS-native surface inventory

This is the companion evidence for the PR2 reset. It is an architect draft and makes no source change.

## Measurement and rule

- Direct census: a Go AST scanner walked every `.go` file outside `.git`/`vendor`, resolved imports of `github.com/nats-io/nats.go` and its subpackages, and selected exported functions, methods on exported receiver types, exported interface methods, exported struct fields, and exported named types whose signatures directly contain a NATS-native type.
- Roots measured: current shared repository at HEAD `900665988afa870dbbe404d1e7f6cf35293fdf8b` plus its visible working tree (83 direct hits), and frozen PR2 evidence root `/private/tmp/semstreams-restart-safe-shutdown` at `991c96bb517f74350cfabce3d55fed7c130b8833` (83 direct hits). The second table records frozen-only seams so concurrent repository evolution cannot erase review evidence.
- A second named-type pass records exported constructors whose signatures use the NATS-bearing local interfaces found by the direct pass.

The tag rule is precise: retire broad mutable ownership roots returned by `Client` or framework constructors—raw `*nats.Conn`, `jetstream.JetStream`, `jetstream.Stream`, `jetstream.KeyValue`, `jetstream.ObjectStore`, or an equivalent capability that permits unbounded work outside Client lifetime. Reviewed narrow value/message/watcher/lister/future seams may remain only with explicit caller context and `Stop`/completion ownership. Full-root input injection defaults to NARROW/REWRITE against a measured local method interface. It may remain only at a named adapter boundary where the caller already owns the root, the callee's documented lifetime owns neither transport close nor root rediscovery, and the API is not a Client/framework convenience constructor. Native value/config/message types are not roots.

Dispositions: **RETIRE** removes a lifecycle/root escape; **NARROW/REWRITE** preserves behavior behind a minimal local interface or framework value; **RETAIN** is already a bounded seam under the rule.

## Release check

The raw-root check is signature-specific, not a ban on all NATS-native types. It fails the tag when an exported Client/framework constructor returns a broad ownership root. Full-root input injection fails unless its row names and proves the adapter-boundary exception; this inventory retains no such exception today. A retained watcher/future/lister requires a context parameter plus documented caller Stop/completion. Every NARROW/REWRITE row must name its measured replacement method set in implementation review; every RETIRE row must have callers migrated and no `Unsafe*` alias.
