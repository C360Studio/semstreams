## The two flagged deviations — recommendations

**§ 6.3 `ErrWorkflowNotRegistered` → Quarantine: ACCEPT the deviation.** It is composition-only and process-wide: `WorkflowName` is a package constant (`agentrun.go:105`), never wire data, and both roots call `agentrun.Register` before constructing the subscriber (`main.go:334`→`:347`; e2e `:261`→`:272`). So if it fires once it fires for every message on both lanes forever. Terminate would permanently drop every milestone with only a WARN each — the silent-drop-at-scale class the contract treats as blocking; Quarantine leaves every delivery unacked and redeliverable once composition is fixed, and surfaces in `/health`. Strongest case against: it departs from the literal deterministic→Terminate ruling, and an unrecorded deviation from a binding ruling is blocking at any severity. The remedy is recording, not reversal — § 2.3 marks the row DEVIATION and § 6.3 explains it, which is the right form; it needs the coordinator's or owner's explicit acceptance, which I cannot give.

**§ 6.4 `ErrEntityNotLifecycleManaged` → Terminate: do not ship Terminate; re-rule.** First choice is Retry bounded by § 2.8, second is nil-run, Terminate last. The sentinel's own doc calls it the ADR-049 Q5 forward-reference case — "exists but no phase triple", i.e. `Manager.Create` has not run *yet* (`errors.go:36-43`). Terminate permanently drops a milestone for a condition the framework documents as expected and that a later `Create` resolves; with B3's finite `MaxDeliver` + `DelayedDeliveryRetry(30s)`, Retry self-resolves inside the ~2-minute budget and otherwise becomes a counted, observable drop on the advisory counter B3 just restored — which is strictly more information than a Term. Strongest case against Retry/nil-run, and it is real: unlike `ErrEntityNotFound` the entity *exists*, so something created it, and handing handlers `run=nil` tells them "not part of a run" when it may be — the silent degrade this layer exists to remove. That argument defeats nil-run; it does not defeat bounded Retry, which stays loud either way. Flagging it to me rather than ruling was correct.
